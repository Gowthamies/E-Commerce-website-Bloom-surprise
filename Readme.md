# 🌸 Bloom Bliss - Flower E-Commerce Website

A modern and responsive flower e-commerce website developed using HTML, CSS, and Bootstrap 5.  
This project presents an elegant online flower shopping experience with visually appealing UI and responsive design.

---

## 🚀 Features

- Responsive design for all screen sizes
- Attractive homepage with hero section
- Product showcase with flower cards
- Add-to-Cart button interface
- Clean navigation bar and footer
- Interactive hover effects
- Modern UI/UX design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

---

## 📌 Project Overview

The Flower E-Commerce Website was developed as a frontend web development project to demonstrate responsive website design and user interface development skills. The project focuses on creating a visually appealing online flower shop with smooth navigation and structured layouts.

---

## 💻 Functionalities

- Display flower products with images and pricing
- Responsive Bootstrap grid layout
- Stylish product cards with hover effects
- User-friendly navigation menu
- Mobile-friendly design
